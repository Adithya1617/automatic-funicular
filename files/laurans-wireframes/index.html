Laurans

UI wireframes

Eight mid-fidelity screens for the Laurans Food Court inventory management system. Click any card to open the rendered wireframe. The implementation spec lives in WIREFRAMES.md.

Operations
01
Dashboard

Landing screen with KPI tiles, low-stock list, top dishes, revenue by channel, reorder suggestions.
02
Live orders

Real-time feed with status filters, source badges, sound + toast on arrival, mark-delivered actions.
03
Ingredients

Table with stock-level bars · expandable movement ledger panel showing every purchase, sale, wastage.
04
Menu item editor

Recipe builder with drag handles, live food-cost calc, BoM-aware availability with bottleneck highlight.
05
Invoice entry

Manual entry with smart per-supplier autocomplete · unmapped rows flagged amber before commit.
06
Stock take

3-step counting flow · order polling paused while in progress · live diff vs book quantity.
07
Manual order entry

Tap-to-add menu picker · channel selector lets you fire mock-Swiggy or mock-POS test orders.
System
08
CSV importer

4-entity tabs · mandatory dry-run · per-row diff with errors and warnings · idempotent on retry.
To use these with Claude Code: drop this whole folder into your repo at docs/wireframes/, then in your build prompts reference the spec file (docs/wireframes/WIREFRAMES.md) and the relevant HTML wireframe by section. Read README.md for the full handoff workflow.
